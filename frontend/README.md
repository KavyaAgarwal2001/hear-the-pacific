# Frontend

Static site, deployed to GitHub Pages from this folder.

- `index.html`, `style.css`, `app.js` — player, chart, controls
- `public/score.json` — generated by `uv run python -m hear_pacific.build`

Audio uses Tone.js 14.8.49 from cdnjs; the chart is a plain canvas.

Run locally:

```bash
python3 -m http.server -d frontend 8000
# open http://localhost:8000
```
